# 집밥흐름 광고 체험용 영양 표시

- 작성일: 2026-09-12
- 범위: 미배포·미머지 homeflow 로컬 후보의 정적 시연 수치.
- 연결: [PRD v0.7](./homecook-flow-round2-prd.md), `lib/marketing/homeflow-content.ts`의 `HOMEFLOW_DEMO_NUTRITION`.

김치볶음밥 영양 정보는 **사용자가 제공한 300g 기준 값**을 단일 기준으로 사용한다. 직접 실측하거나 별도 자료로 정확성을 검증한 값이라고 주장하지 않는다. 실제 음식 데이터 API·DB·식품 원장·공식 제품 영양 계약은 변경하지 않는다.

## 표시값과 합산

| 구분 | 열량 kcal | 탄수화물 g | 단백질 g | 지방 g | 기준 |
| --- | ---: | ---: | ---: | ---: | --- |
| 기존 아침·점심 시연 합계 | 1,120 | 146 | 72 | 38 | 기존 광고 시연 데이터 |
| 저녁 김치볶음밥 300g | 608 | 56 | 25 | 32 | 사용자 제공 |
| 저녁 기록 뒤 시연 합계 | 1,728 | 202 | 97 | 70 | 앞의 두 행을 항목별 합산 |

합산은 `1120 + 608 = 1728`, `146 + 56 = 202`, `72 + 25 = 97`, `38 + 32 = 70`이다. 값은 재추정하거나 다른 데이터로 덮어쓰지 않는다.

저녁 음식 행에는 **300g · 608 kcal**를 표시한다. 작은 안내는 **영양정보 · 체험 예시**, 상세 문구는 **김치볶음밥 300g의 영양정보를 반영했어요.**다. 그 값의 출처는 사용자 제공임을 이 문서에 명시한다. 완성 요리 600g 가정과 관련 상세 설명은 삭제한다.

기존 아침 **그릭요거트 볼 250g · 420 kcal**, 점심 **닭가슴살 현미밥 400g · 700 kcal**는 별도로 준비된 광고 시연 데이터다. 이 두 음식의 성분에서 C146/P72/F38을 새로 역산한 것이 아니다. 기존 합계는 탄수화물·단백질 4kcal/g, 지방 9kcal/g 환산과 정확히 맞지 않으며 실제 사용자의 음식 분석 결과로 취급하지 않는다.

## 제외한 이전안

RDA 재료 가중합과 완성 600g을 가정했던 추정안은 최신 사용자 제공 값으로 대체해 폐기했다. 해당 가정·추정 수치를 현재 코드·화면·검증 기준에 혼합하지 않는다.

300g은 섭취 체험값이다. 완성 중량·나머지 음식 양을 계산하거나 남은 음식 기록을 자동 생성하지 않는다. 영양 정보 제공은 영상의 조리 순서·불 세기·시간 확인을 대신하지 않는다.

## 검증 범위

- 표의 합산을 확인하고 `HOMEFLOW_DEMO_NUTRITION`의 baseline/dinner/total과 대조한다.
- 사용자 제공 수치의 실측 과정·정확성을 독립 검증했다고 주장하지 않는다.
- 새 이미지·화면·모션을 포함한 이번 변경의 통합 검증은 진행 중이다. 이전 UI 통과 기록을 이번 변경의 통과 증거로 사용하지 않는다.
- 운영 DB/API 변경, 배포, master 머지는 수행하지 않는다.
