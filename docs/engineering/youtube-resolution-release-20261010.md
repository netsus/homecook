## 이번 통합 범위

최신 master의 단위 근거·영양 표시 변경 위에 기존 재료 연결 작업만 옮겼다. 원본 미커밋 작업트리와 다른 세션의 진행 중 변경은 보존한다. 미배포 v64 장면 선택·OCR·분량 표시 변경은 이 단계에 포함하지 않는다.

검토 중 발견한 다음 문제를 보완한다.

- 스파게티는 원문 전체가 `Spaghetti + 해당 재료의 질량`인 경우만 면 후보를 더한다. 브랜드·소스·호박·조리 상태·단위 불일치는 자동 확정하지 않는다.
- 재료 이름 후보와 실제 매칭 함수의 정의·권한 변경을 배포 준비 검사에서 탐지한다. 기대값은 격리 환경의 소스로 계산한다.
- 저장된 개인 레시피에 현재 행별 연결 정보를 읽기 전용으로 표시한다. 사용자가 수정한 내용·원본 snapshot·revision·분량을 다시 쓰지 않는다. 이름을 바꾸거나 원본 연결을 해제한 행은 옛 ID를 상속하지 않는다.
