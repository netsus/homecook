- 저장된 개인 레시피에 현재 행별 연결 정보를 읽기 전용으로 표시한다. 사용자가 수정한 내용·원본 snapshot·revision·분량을 다시 쓰지 않는다. 이름을 바꾸거나 원본 연결을 해제한 행은 옛 ID를 상속하지 않는다.
