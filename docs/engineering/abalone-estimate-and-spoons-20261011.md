# 전복 추정 중량 반영과 숟가락 기준 제안

상태: 전복50g 운영 반영·영양갱신·과거보존 검증 완료. 숟가락 표는 검토용으로 아직 적용하지 않음.

## 전복

사용자가 전복1개를 껍데기·입을 제외한 먹는부분50g으로 계산하도록 승인했다. 이는 AI 추정 중량이며 실제 측정치·모든 크기의 전복 표준값이 아니다. 내장 사용 여부는 원래 레시피 손질 방식에 따른다. 기존100g/개 연결은 원본값을 보존한 채 새50g 연결로 대체한다.100g당 공식 영양자료는 수정하지 않는다. 명시적으로 입력한g은 기존처럼 우선한다.

현재 개수 사용은 전복리조또1행(1개)이다. 표시 수량은1개 그대로 두고 계산 중량만100→50g이다. 레시피 전체의 예상 열량은771.5402→732.0402kcal, 탄수화물99.355013→97.105013g, 단백질27.712087→21.262087g, 지방27.63172→27.38172g이다. 이는 전복 기여분만 절반으로 바꾸는 것이며 요리 전체를 절반으로 줄이는 것이 아니다. 실제 검증 결과는 아래에 기록한다.

## 스푼·숟가락 정리 제안

1. **명시된 계량단위:** 큰술/T/tbsp는15ml, 작은술/t/tsp는5ml. 기존 공식 환산을 유지한다.
2. **밥숟가락으로 확인된 표현:** 식재료별 추정값을 별도로 사용한다. 우선 아래 표를 검토 기준으로 삼고, 실제 도구의 부피나 담은 무게가 있으면 그 값을 우선한다.
3. **스푼·숟가락만 있고 크기가 불명확한 표현:** 원문·영상에서 도구와 담는 방식을 먼저 확인한다. 표의값으로 일괄 덮어쓰지 않는다.
4. **수북이·듬뿍·꾹 눌러:** 평평한 숟가락과 구분한다. 정해진 배수를 곱하지 않고 실제량 또는 해당 조건의 별도 근거를 확인한다.
