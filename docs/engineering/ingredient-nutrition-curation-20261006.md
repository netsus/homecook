# 참깨·두부·양상추 영양 오연결 교정 — 2026-10-06

상태: **full-local 운영 DB 반영 완료**. 후보 매칭 보완 코드는 `codex/ingredient-nutrition-correction-20261006` 작업트리에 있으며 아직 머지하지 않았다. 웹 배포는 하지 않았다.

사용자는 전체 재료 검토 후 잘못 연결된 세 재료부터 교정하는 순서를 승인했고, 테스트 레시피 보존보다 재료 영양 정확성을 우선한다고 명시했다. 이번에는 재료·레시피를 삭제할 필요가 없어 삭제하지 않았다. 나머지 영양 검토 41개, 미연결 352개와 부분 결측 218개의 보완은 이번 반영에 포함하지 않는다.

## 확인한 원인과 재발 방지

현재 잘못된 연결의 결정 이유는 9월 14일 RDA 수입의 ‘식품명 구성요소와 표준명/동의어 exact 일치’였다. 송편의 `깨`, 햄버거의 `양상추`처럼 **완성식품에 포함된 재료명**을 식품 자체의 일치로 취급했다. 일반 두부와 동결건조 두부의 상태 차이도 빠졌다. 해당 일회성 수입 스크립트는 저장소/Git 이력에서 찾지 못했으므로 실제 실행 주체와 호출 경로는 확정하지 않는다. 이를 사용자가 세 오연결을 승인한 결과로 설명하지 않는다.

잘못된 전체 원자료명 3개가 재료 별칭으로도 등록돼 있어 함께 제거하고 기존 행은 운영 감사 이벤트에 남겼다. 기존 공유 원자료와 프로필의 수치는 삭제·변조하지 않고, 잘못된 재료 연결만 `superseded`로 대체했다.

`scripts/lib/nutrition-gap-candidates.mjs`는 **검토 후보 생성기**이며 이 세 후보를 스스로 승인하던 함수는 아니다. 이번 보완은 햄버거·쌀떡의 부재료 단어와 오염된 전체 별칭만으로 다른 재료에 매칭되는 경로 및 명시되지 않은 동결건조 상태를 차단한다. 일반적인 품목/별칭 매칭과 괄호 동의어, 실제 떡 하위 품목은 유지한다. 모든 복합식품을 해결하는 범용 식품 분류기로 표현하지 않는다.

독립 비교에서 기존 후보 1,596쌍 중 1,592쌍을 유지하고 양상추→햄버거, 참깨→송편, 두부→동결건조, 콩고물→인절미 4쌍을 제외했다. **콩고물의 실제 DB 연결은 이번에 수정하지 않았다.** 정상 후보가 과도하게 사라지는 초기 수정은 폐기했으며 청양고추·오트밀·백김치·말린 녹두와 정상 떡 8종을 회귀 검사에 포함했다.

## 반영과 검증

- 기존 full-local config의 정확한 Compose project·이미지 digest·컨테이너·volume·로컬 Unix socket을 확인했다. Cloud/linked DB를 사용하지 않았다.
- 변경 직전 DB 전체 백업 116,632,177bytes를 저장소 밖 소유자 전용 파일로 만들고, 운영 볼륨/포트가 없는 네트워크 격리 PostgreSQL에 실제 전체 복원했다. 이는 이번 DB 교정의 백업이며 전체 플랫폼 off-Mac 복구 점검을 새로 수행했다는 뜻은 아니다.
- 복제본에서 이전 링크 변경 감지, 별칭 검증의 후반 실패 시 전체 취소, 세 연결 교정, 24개 값 대조, 무관한 사용자/레시피 행 보존, 재실행 무변경을 확인했다.
- 운영 데이터 반영: **2026-10-06 17:48 KST**. 세 재료 연결·잘못된 전체 원자료 별칭만 교정했다. 영향받는 현재 레시피 24개는 기존 계산기·DB 입력 일치 검사·스냅샷 writer를 이용해 새 영양 snapshot24개를 만들었다. 재실행 추가 쓰기0·새 snapshot0을 확인했다.

## 재현 자료와 남은 범위

`node scripts/render-ingredient-curation-20261006.mjs`는 검수 JSON의 두 checksum을 검사한 후 SQL만 출력한다. DB 연결이나 실행을 하지 않는다. 실제 반영은 정확한 로컬 대상과 새 백업을 확인한 운영 절차에서만 한다. SQL은 이전 링크·식품코드·별칭을 고정하고 한 트랜잭션에서 적용하며 완료 기록이 있으면 무변경 종료한다.

영양 근거는 [농촌진흥청 공식 DB 안내](https://www.nics.go.kr/food/kfi/fct/fctIntro/list?menuId=PS03562)의 10.4 파일을 2026-10-06 다시 내려받아 확인했다. 파일 SHA-256 `271cc431f2991b3c0c049ec6e05fb59a040319e984ab71468184530de61dec50`, 13,348,408bytes로 기존 고정 원본과 일치했다. 출처: 농촌진흥청, 2026. 국가표준식품성분 DB 10.4. 공공누리 제1유형(출처표시).

`볶은깨`·`동두부`처럼 범용 재료에 연결된 상태별 별칭의 분리는 후속 카탈로그 검토 대상이다. 이번에 제거한 것은 잘못된 전체 영양 원자료명 세 개이며, 나머지 별칭까지 모두 정확하다고 판정한 것은 아니다. 원자료 숫자가 있는 것과 식품 정체성/단위가 정확하게 일치하는 것은 계속 구분한다.
