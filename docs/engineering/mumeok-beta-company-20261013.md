상태: 구현·독립 리뷰 확인, 운영 미반영. v9의 C06-B0~B3이며 사진 수집 계획은 대체되어 실행하지 않는다.

## 표시 계약

- public_dataset 제품의 기존 박스 자리에 등록업체명을 표시한다. 이름으로 제조사/브랜드를 추측하지 않고 manual 제품의 사용자 브랜드는 그대로 둔다.
- 원문 brand는 변경하지 않는다. 비교용 NFKC/공백 정리, 검토된 샘표6원문 정확 별칭, 명확한 법인 표기 제거만 사용한다. 식품·산업·공장·지점은 일반 규칙으로 지우지 않는다.
- 정리 전후 빈값·명확한 placeholder·기호만 남는 값은 ‘제품’/‘등록업체 정보 없음’으로 표시한다.
- 공공제품 목록의 중복 업체명/영양 UUID 줄은 제거하고 선택 확인 칩에서 전체 원문을 제공한다. 접근성 이름에는 제품명·전체 등록업체·선택/보유 상태를 제공하고 UUID는 읽지 않는다.
- 모바일 제품 검색은1열과48px 배지, 선택 칩 줄바꿈을 사용한다. 일반 재료2열·데스크톱4열은 유지한다.
- 제품 ID·고정 영양 버전·검색 키·과거 snapshot·DB·API 저장 데이터는 불변이다. 이미지/Storage/DB 작업0.
