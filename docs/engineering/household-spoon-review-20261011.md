# 원문 확인에 따른 밥숟가락 중량 반영

상태: 2026-10-11 운영 반영 완료. 사용자가 승인한 11종 추정표를 원문과 대조해 적용 가능한 7종만 반영했다.

## 결과와 표시

5개 레시피의 스푼·숟가락 27행을 검토했다. 공개 원본 2개와 연결된 개인 사본 2개의 **16행**을 `밥숟가락`으로 구분하고, 영양·내용 저장본을 각각 4개 추가했다. 나머지 **11행**은 수북한 정도·분량 충돌을 해결하지 못해 기존 값을 유지했다. 대상 영상에서 15ml 계량큰술로 확정한 행은 없었다.

| 재료 | 평평한 밥숟가락 1개 추정 중량 | 적용 예 |
| --- | ---: | --- |
| 굴소스 | 15g | 1밥숟가락 → 15g |
| 멸치액젓 | 14g | 1밥숟가락 → 14g |
| 양조간장 | 14g | 2밥숟가락 → 28g |
| 올리고당 | 12g | 1밥숟가락 → 12g |
| 다시다 | 8g | 0.5밥숟가락 → 4g |
| 양조식초 | 12g | 1밥숟가락 → 12g |
| 맛술 | 10g | 2밥숟가락 → 20g |

화면에는 `양조간장 1밥숟가락`처럼 수량·단위를 표시하고 영양 계산에만 추정 g을 사용한다. 기존 수량, 원문 표시 문자열, 조리 단계, 출처는 보존했다. 기존 `큰술`·`T`는 15ml, `t`는 5ml이며, 모호한 기존 `스푼`·`숟가락`·`밥숟갈`의 15ml 처리도 이번에 전역 변경하지 않았다.

## 원문 판정

- [돼지고기 원영상](https://www.youtube.com/watch?v=2aszTDFuueA): 맛술·간장·식초·굴소스는 밥숟가락으로 확인했다. 마늘은 수북하고, 소금은 작은 봉우리·분할 계량이라 평평한 기준을 확정하지 못했다. 설탕은 수북한 데다 영상 자막 4와 설명·저장값 2가 다르므로 수량도 변경하지 않았다. [상세 근거](data/spoon-source-pork-20261011.json).
- [두부찌개 원영상](https://www.youtube.com/watch?v=2KoUycJinko): 간장·액젓·올리고당·다시다에 적용했다. 마늘·고춧가루는 수북하거나 평평한 담음이 확인되지 않았다. [상세 근거](data/spoon-source-tofu-20261011.json).
- [간장국수 원영상](https://www.youtube.com/watch?v=OlHcm42NmYE): 마늘 덩어리가 수북해 기존 `1숟가락`을 유지했다. [상세 근거](data/spoon-source-noodles-20261011.json).

개인 사본은 원본 연결과 해당 재료·수량·단위·그룹 등이 동일한 행만 적용했다. 개인 식별정보와 전체 원본 데이터는 비공개 운영 기록에 보존했다.

## 근거와 구현 범위

영상은 도구와 담음 상태를 확인하는 근거이며 실제 용량·무게 측정이 아니다. 위 g은 **밥숟가락 11.5ml 가정과 기존 재료별 15ml 중량을 바탕으로 사용자가 승인한 정수 추정값**이다. 제품 농도·도구 크기에 따라 오차가 있고 수북한 숟가락에는 적용하지 않는다. 공식 100g 영양값을 AI 값으로 바꾼 것이 아니다.

기존 개수 중량 체계에 `household_spoon` 분류만 추가했다. 새 중량 근거 7개와 연결 7개·출처 1개를 추가하며 기존 부피 환산은 그대로 둔다. 별도 계산기나 외부 AI 호출은 추가하지 않았다. AI 자동 보완은 계속 꺼져 있다.

전역 단위 목록·공개 작성 함수의 허용 목록은 확대하지 않았다. 검토된 원본의 `밥숟가락`은 기존 신뢰 원문 단위 예외를 통해 같은 재료·그룹의 수정/포크에서 보존된다. 임의 신규 수기 레시피에 이 단위를 일반 허용한 작업은 아니다. 이 방식으로 worker의 공개 함수 계약과 catalog fingerprint를 보존했다.

주요 파일: `lib/nutrition/ingredient-piece-units.mjs`, `supabase/migrations/20261011200000_household_spoon_measurement.sql`, [고정 승인 계획](data/household-spoon-weight-plan-20261011.json), `scripts/render-household-spoon-weights.mjs`와 관련 테스트.

## 남은 범위

수북한 설탕·고춧가루·소금·다진마늘은 평평한 추정값을 일괄 적용하지 않았다. 원문의 분량 확인 또는 해당 담음의 실측/별도 승인 추정이 필요하다. 원문과 수량이 크게 다른 기존 개인 사본 1행도 이번 범위 밖이라 별도 확인 대상으로 남겼다.
