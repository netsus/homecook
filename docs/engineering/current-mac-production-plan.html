서비스는 지금 운영 중이다

production build가 현재 Mac에서 백그라운드로 실행되고 있다. 홈, 실제 레시피 데이터, 상세 화면, 모바일 화면, 재시작 복구까지 확인했다.

홈쿡 production 열기
현재 Mac 전용 127.0.0.1은 내 컴퓨터를 뜻한다. 같은 와이파이의 휴대폰이나 인터넷 사용자는 이 주소로 접속할 수 없다.
실행 방식Next.js production build를 launchd가 실행한다.
자동 복구프로세스가 종료되면 launchd가 다시 시작한다.
환경 파일.env.production.local은 허용 키만 담고 권한은 600이다.
잠자기 방지Amphetamine을 계속 실행해 Mac sleep을 막는다.

문제를 근본적으로 해결한 내용

1

원격 DB가 코드보다 뒤처짐

원격 Supabase에 recipes.visibility와 후속 schema가 없어 홈 API가 PostgreSQL 42703으로 실패했다.

DB를 먼저 백업하고 빠진 공식 migration 33개와 이번 보안 migration을 순서대로 적용했다.

2

visibility guard의 schema 권한 부족

guard 함수 소유자가 테이블은 읽을 수 있지만 public schema 이름을 해석할 수 없었다.

USAGE만 허용하고 CREATE는 계속 금지해 최소 권한을 유지했다.

3

Supabase hosted 검색 함수 제한

함수 내부의 pg_trgm.word_similarity_threshold 변경이 hosted 환경에서 42501로 거부됐다.

short-ngram GIN index로 후보를 줄이고 word_similarity > 0.3을 명시해 같은 검색 의미와 성능을 유지했다.

4

DB 기본 권한과 검증기 오판

레시피 관련 직접 쓰기 권한은 넓게 남았고, 허용 열만 공개한 tags와 PostgreSQL 17 제한형 역할은 검증기가 잘못 판단했다.

table·column 쓰기 권한을 회수하고, 공개 열과 안전한 Supabase 역할 형태를 정확히 검사하도록 수정했다.

5

pnpm 설정 위치와 Node 경로

최신 pnpm 설정 위치가 바뀌었고 현재 셸에는 시스템 node가 없었다.

설정을 pnpm-workspace.yaml로 옮기고, 검토한 build script 버전만 허용하며, 관리 명령이 현재 Mac의 Node를 자동 탐색하게 했다.

운영할 때 쓰는 명령

상태 확인

서비스가 켜져 있는지 본다.

./scripts/run-local-mac-production.sh status

재시작

새 build를 반영하거나 일시 오류를 복구한다.

./scripts/run-local-mac-production.sh restart

오류 로그

서버가 켜지지 않을 때 마지막 오류를 본다.

tail -n 100 ~/.homecook/logs/homecook-production.err.log

다시 설치

새 build를 만든 뒤 환경·품질 검사를 거쳐 다시 등록한다.

./scripts/run-local-mac-production.sh build
./scripts/run-local-mac-production.sh install

운영 해제

자동 실행을 멈추고 launchd 등록을 지운다.

./scripts/run-local-mac-production.sh uninstall

장애가 보일 때 확인 순서

  1. production 주소를 다시 연다.
  2. ./scripts/run-local-mac-production.sh status에서 running: yes인지 확인한다.
  3. ./scripts/run-local-mac-production.sh restart를 실행한다.
  4. 계속 실패하면 오류 로그 마지막 100줄을 확인한다.
  5. 코드를 바꿨다면 운영 래퍼의 build 후 install을 실행한다.
  6. 환경 변수만 바꿨다면 운영 래퍼의 install을 다시 실행한다.

계속 지켜야 할 안전선

  • secret과 .env.production.local을 Git에 올리지 않는다.
  • SUPABASE_SERVICE_ROLE_KEY를 브라우저 변수로 만들지 않는다.
  • 127.0.0.1 제한을 임의로 풀지 않는다.
  • Mac 전원과 Amphetamine 상태를 유지한다.

아직 포함하지 않은 것

  • 같은 와이파이의 다른 기기 접속
  • public internet 공개
  • 도메인과 HTTPS
  • OAuth production callback 변경
  • 실제 Mac 재부팅 smoke test
