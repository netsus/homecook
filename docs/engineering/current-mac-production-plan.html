homecook 2026-07-29 activation blocked Mac production

현재 Mac에서 집밥 서비스를 production처럼 운영하기

localhost 개발 서버를 그대로 공개하지 않고, production build, 환경 변수, 검증, launchd 상시 실행까지 순서대로 이해하는 초보자용 안내서다.

현재 상태 운영 코드와 launchd 검증은 끝났지만 연결된 Supabase DB에 recipes.visibility가 없어 실제 서비스는 안전하게 중지했다. 공식 migration 적용 후 품질 게이트를 다시 통과해야 한다.

!딱 한 줄 요약

production 운영 도구와 build는 준비됐지만, 원격 DB migration이 코드보다 뒤처져 있어 live activation은 차단된 상태다.

비유: pnpm dev는 요리 연습용 주방이고, pnpm build && pnpm start는 같은 레시피를 손님에게 내기 전에 실제 판매 주방에서 다시 만드는 과정이다.

중요 현재 Mac에서 production build를 돌리는 것과 외부 사용자에게 안전하게 공개하는 것은 다르다. 외부 공개는 도메인, HTTPS, OAuth callback, 법률/신뢰 페이지, 네트워크 보안 계획이 추가로 필요하다.

1헷갈리는 구분

먼저 해도 되는 것

  • pnpm build로 production build를 만든다.
  • corepack pnpm start -- -H 127.0.0.1 -p 3100으로 현재 Mac 안에서만 확인한다.
  • 검증이 끝난 뒤 launchd로 자동 실행을 붙인다.

바로 하면 위험한 것

  • pnpm dev를 production이라고 생각하고 공개한다.
  • .env.local을 그대로 복사해 QA flag까지 운영에 올린다.
  • HTTPS 없이 public internet에 로그인 서비스를 연다.
구분명령 또는 예시용도주의
개발 서버pnpm dev코드를 고치면서 바로 확인production 성능/보안 조건과 다르다.
production buildpnpm build실제 운영 전에 앱을 컴파일실패하면 운영 시작 금지.
production serverpnpm startbuild 결과물을 실제 실행먼저 pnpm build가 필요하다.
local-only 운영-H 127.0.0.1현재 Mac에서만 접속외부 사용자는 못 들어온다.
LAN 운영-H 0.0.0.0 + Mac 내부 IP같은 와이파이/사내망에서 접속방화벽과 IP 노출 범위를 확인한다.
public internet 운영도메인 + HTTPS + reverse proxy/tunnel외부 사용자 접속현재 계획에서는 후속 단계다.

2알아둘 용어

localhost local address
내 컴퓨터 안에서만 통하는 주소다. 보통 127.0.0.1과 같다.
production build release build
개발용이 아니라 실제 운영에 가까운 방식으로 앱을 컴파일한 결과다.
pnpm package manager
이 repo의 패키지 설치와 실행 명령을 담당하는 도구다. 현재 기준은 pnpm@10.32.1이다.
Next.js framework
이 서비스의 웹 앱 프레임워크다. 현재 repo는 next@15.5.21를 쓴다.
.env.production.local env file
production 실행에 필요한 비밀값과 주소값을 담는 로컬 파일이다. Git에 올리면 안 된다.
Supabase backend service
로그인, DB, API 접근에 쓰는 외부 백엔드 서비스다.
service role key server secret
서버에서만 써야 하는 강한 권한의 키다. 브라우저에 노출되면 위험하다.
launchd macOS service manager
Mac에서 앱을 백그라운드로 켜고, 죽으면 다시 시작하게 해주는 기본 기능이다.
host binding -H option
서버가 어떤 주소에서 접속을 받을지 정하는 설정이다. 127.0.0.1은 내 Mac 전용, 0.0.0.0은 네트워크 접속 허용이다.
LAN local network
같은 와이파이나 사내망처럼 가까운 네트워크 범위다.
CSP Content Security Policy
브라우저가 불필요한 외부 스크립트나 연결을 막도록 하는 보안 헤더다.
smoke test quick check
모든 걸 깊게 보지는 않지만, 서비스가 큰 문제 없이 뜨는지 빠르게 확인하는 테스트다.

6환경 변수 준비

production에서는 .env.local을 그대로 복사하지 않는다. 개발용 flag와 secret이 섞여 있을 수 있으므로 .env.example과 운영 목적을 기준으로 .env.production.local을 따로 만든다.

secret 주의 SUPABASE_SERVICE_ROLE_KEY는 서버 전용 master key에 가깝다. NEXT_PUBLIC_ 접두사를 붙이면 브라우저로 노출될 수 있으므로 절대 붙이지 않는다.

최소 필수 후보

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
NEXT_PUBLIC_APP_URL=
NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_ENABLED_AUTH_PROVIDERS=

이번 Mac의 local-only 값

HOMECOOK_PRODUCTION_EXPOSURE=local-only
NEXT_PUBLIC_APP_URL=http://127.0.0.1:3100
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:3100

production에서 켜면 안 되는 값

HOMECOOK_ENABLE_QA_FIXTURES=1
NEXT_PUBLIC_HOMECOOK_ENABLE_QA_FIXTURES=1
HOMECOOK_ENABLE_LOCAL_DEV_AUTH=1
NEXT_PUBLIC_HOMECOOK_ENABLE_LOCAL_DEV_AUTH=1
NEXT_PUBLIC_HOMECOOK_ENABLE_LOCAL_GOOGLE_OAUTH=1
HOMECOOK_YOUTUBE_FIXTURE_PROVIDER=fixture

주소 값 선택 규칙

운영 모드NEXT_PUBLIC_APP_URL / NEXT_PUBLIC_SITE_URL 예시판단
현재 Mac에서만 확인http://127.0.0.1:3100이번에 구현한 local-only 주소다. Mac 밖에서는 접속할 수 없다.
같은 네트워크에서 확인http://192.168.0.25:3000LAN 내부 테스트 후보. Mac IP가 바뀌면 다시 수정해야 한다.
실제 사용자 공개https://your-domain.example권장 production 후보. HTTPS, OAuth callback, legal/trust 점검이 필요하다.

app/layout.tsx는 NEXT_PUBLIC_SITE_URL이 없으면 https://homecook-flame.vercel.app를 fallback으로 사용한다. 현재 Mac을 기준 주소로 쓰려면 NEXT_PUBLIC_SITE_URL을 명시한다.

8launchd 운영 명령

plist를 직접 만들거나 수정하지 않는다. 저장소 스크립트가 DB 품질 게이트를 먼저 실행하고, 현재 Node 절대 경로, local-only host, 자동 재시작, 로그 위치를 일관되게 생성한다. HTTP 준비에 실패하면 설치를 자동 롤백한다.

corepack pnpm mac-production:install -- \
  --node-bin /Users/cwj/.nvm/versions/node/v22.19.0/bin/node \
  --port 3100

corepack pnpm mac-production:status
corepack pnpm mac-production:restart
corepack pnpm mac-production:uninstall
초보자 포인트 plist 안에 secret 값을 직접 넣지 않는 편이 좋다. secret은 Git ignored 상태의 .env.production.local에 두고, plist에는 실행 방법과 NODE_ENV=production처럼 민감하지 않은 값만 둔다.

9판단 규칙

local-only로 진행나 혼자 현재 Mac에서 production build 동작만 확인하려는 경우. host는 127.0.0.1을 쓴다.
LAN-only로 확장같은 와이파이 또는 사내망 사용자만 접속하면 되는 경우. host는 0.0.0.0이고 접속 주소는 Mac 내부 IP다.
public internet은 별도 계획외부 사용자를 받으려면 도메인, HTTPS, OAuth callback, legal/trust, 방화벽, 로그 정책을 먼저 잠근다.
즉시 중단pnpm build, production 품질 게이트, 보안 헤더 확인 중 하나라도 실패하면 운영 시작을 멈춘다.

13다음 의사결정

local-only-> LAN-only-> 도메인/HTTPS-> public production
  1. Supabase CLI를 연결하고 원격 pending migration을 공식 순서대로 적용한다.
  2. 품질 게이트와 브라우저 smoke가 통과하면 mac-production:install을 다시 실행한다.
  3. 현재 구현은 local-only로 유지한다. LAN/public으로 넓힐 때 host 제한을 임의로 풀지 않는다.
  4. public internet이면 도메인, HTTPS, OAuth callback, 법률 문서와 네트워크 보안 계획을 별도로 잠근다.
