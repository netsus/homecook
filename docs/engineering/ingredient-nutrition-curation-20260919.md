상태: 2026-09-19 full-local 운영 DB 반영 완료. 별도 웹 코드 배포 없이 기존 운영 API에서 갱신된 값을 확인했다.

기존 30개는 영양 연결이 없던 재료 중 레시피 참조가 있는 목록이다. 삭제된 레시피만 참조하는 재료도 포함되어 있다. 이름·상태·가식부 100g 기준이 확정된 9개를 연결하고, 모호한 21개는 후보로 남긴다. 별도로 쌀밥 오연결 1개를 정정한다.

## 중복과 검색 이름

- 비활성 `생 돼지고기 목심`에서 `돼지고기 목심`으로 대표 연결 1건을 기록한다. 같은 1704 profile을 공유하며 기존 ID와 레시피 참조를 바꾸지 않는다. 비활성 ID의 기존 검색 제외 정책도 유지한다.
- `돼지고기 앞다리`는 일반 앞다리1721, `돼지 앞다리살`은 별도 기존 기준을 유지한다. 두 ID를 병합하지 않는다. `돼지 앞다리` 별칭은 일반 앞다리로 옮기고 `돼지고기 앞다리살` 별칭은 앞다리살에 유지한다.
- 대표 연결표는 검토 기록이다. 과거 사용자 기록의 재료 ID를 자동 치환하는 API는 추가하지 않는다.
