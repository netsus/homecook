# 2026-10-07 화면 개선·재료 DB 작업 통합 배포

사용자가 현재 화면 개선 전체와 완료된 재료 DB 작업을 함께 머지·배포하도록 요청했다. 유튜브 추출 재설계의 미완성 작업과 과거 보존 작업트리는 제외한다.

## 준비 완료 범위

- 요리계획/식사기록 설계 및 실화면 피드백, 하단 추가 모달·입력·스크롤, 요리모드, 레시피북 표시와 활동 알림.
- 영양 미리보기(읽기 전용)와 계획 중복 저장 방지, 기존 권한/상태 보호.
- 완료된 재료 영양 교정·카탈로그 정의·원자료 확장 코드/문서/검사. 새 카탈로그 분류를 화면에 연결하는 추가 기능은 범위 밖이다.
- 독립 검토에서 식사 상세 위 추가 모달이 가리는 오류를 수정하고 실제 모바일/데스크톱 화면으로 확인했다. 보안 함수 명세 누락과 검사기의 SQL 문법 지원도 보완했다.

## DB 상태

실제 full-local DB는 201개 migration이다. 재료 작업의 아래 3개 SQL은 이미 적용됐고 원본 checksum과 일치한다. 데이터 가져오기/정리 SQL은 다시 실행하지 않는다.

- 20261007143000_ingredient_catalog_organization.sql
- 20261007160000_ingredient_catalog_definitions.sql
- 20261007210000_ingredient_source_name_capacity.sql

이번 추가 적용은 알림/영양미리보기/계획멱등 SQL 3개이며 최종 원장은 204개다. 현재 201개 중 최신 3개가 먼저 적용된 관계로 prefix 비교 대신 전체 기존 파일명·checksum 보존과 최종 전체204개 일치를 검사한다. 허용된 현재 source/manifest에 한정하고 범용 이력 생략 기능을 추가하지 않는다.

## 검증과 보호

- 관련 웹/영양 회귀 1,252개 통과(수정된 runner의 레시피 GET 4건 포함), 배포 경계 102개 통과. 이전·무관한 전체 fixture suite가 모두 통과했다는 뜻은 아니다.
- 모바일375px/데스크톱1280px 화면/흐름10개와 상세→음식추가의 실제 겹침 확인2개 통과.
- 새 SQL3개를 현재 스키마의 네트워크 없는 격리 DB에서 적용/rollback한 뒤 권한·함수·스키마 불변과 기능33개를 확인했다. 사용자 데이터는 복원하지 않았다.
- 현재 전체 DB의 새 논리 백업, 전체 플랫폼 암호화 백업·외장 사본·격리 복원·키 복구 검증 완료. 기존 서비스 ID/설정은 보존하고 백업 증거 경로만 갱신했다.
- 운영 데이터가 있는 DB reset/볼륨 삭제나 Supabase Cloud 접근 없음.

## 반영 결과

아직 실행 전이다. 머지·SQL 적용·웹 배포 후 정확한 PR/commit/build와 확인 결과를 갱신한다.
