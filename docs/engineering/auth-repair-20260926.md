# 회원가입·로그인·계정 복구·연결 점검 — 2026-09-26

사용자는 휴대폰에서 네이버 로그인 제한, 탈퇴 후 Google 재로그인의 계정 복구 실패를 보고하고 회원가입·로그인·계정 연결을 요청했다. 후속으로 별도 LAN 설정 대신 검증된 수정을 기존 `https://app.mumeok.kr`에 반영하며 확인하기로 선택했다.

## 원인과 변경

- 네이버: 앱이 개발 중이어서 앱 개설자·관리자·등록된 테스트 ID만 로그인할 수 있었다. 사용자 지정 테스트 ID를 개발자센터에 등록하고 새로고침 후 유지되는 것을 확인했다. 일반 사용자 가입은 네이버 로그인 검수 완료가 필요하다. 첨부된 가로 잘림은 `nid.naver.com`의 제한 안내 화면이며 앱 CSS를 수정하지 않는다.
- 계정 복구: `resolve_account_cutover_quarantine`의 기존 구현이 이전 인증 전환 때 점검 오류만 반환하도록 남아 있었다. 검증된 full-local 인증 세션을 받는 내부 overload로 복구와 세션 권한 등록을 같은 트랜잭션에서 처리한다. 과거 세션·다른 소유자·변경된 identity·만료 세션을 허용하지 않고 요청 키의 중복 방지를 유지한다.
- 계정 연결: self-hosted Auth에 빠진 `GOTRUE_SECURITY_MANUAL_LINKING_ENABLED=true`를 명시한다. 연결 시작 실패 시 기존 연결 목록을 유지하고 다시 시도할 수 있게 한다. 목록 조회 실패는 재조회 버튼, 만료 세션은 로그인 이동을 제공한다.

## 확인과 운영 상태

- 로그인·회원가입·계정 연결 관련 Vitest 9파일 183개 통과.
- 격리 PostgreSQL 41개 통과(기존 suite의 비실행 30개와 구분). 실제 복구·세션 갱신·중복 요청·타 소유자/만료/폐기 세션 거부·후단 실패 전체 롤백을 확인했다. 관련 API·화면·세션 Vitest 56개 통과.
- 연결 UI의 320/390/1440px 브라우저 검사 12개, TypeScript 검사, 변경 파일 ESLint와 보안 함수 계약 검사 통과. 연결 시작 실패를 의도적으로 반환했을 때 목록 유지와 재시도를 확인했다. 브라우저 실행 오류는 없고, QA에 준비되지 않은 기존 알림 조회 401은 별도로 기록했다.
- 별도 읽기 전용 코드 검토에서 배포를 막을 결함은 발견되지 않았다. 신규 SQL SHA-256은 `08de74cffef75639eb34db64fd36d968af6ec86560c2d8b96109a402691a7dee`다.
- 네이버 테스트 ID 등록은 완료했다. 계정 ID와 비밀값은 이 문서에 기록하지 않는다.
- 운영 DB 초기화·volume 삭제·세션 보호 우회 없이 변경 전 백업과 대상 확인 후 반영한다.
- 운영 반영 전 백업 검사에서 외장 `HomecookOffMac`이 일시적으로 인식되지 않았다. 재확인 시 기존 두 드라이브가 모두 연결됐다. 9월 22일 전체 백업은 24시간 기준을 넘었으므로 새 전체 백업·외장 복사·격리 복원·서명 검증을 진행한다. 실제 소셜 로그인과 복구 완료 여부는 운영 반영 후 확인 대상이다.
- 실행 중인 웹을 부모로 한 코드 전용 후보 `5d05a180b`의 앱 4파일은 원본 수정 `20f37c565`와 동일하다. 이 후보에서 인증 검사 160개, 기존 웹/API 회귀 239개, production build가 통과했다. DB 함수와 Auth 구성은 별도 통제 적용하며 웹 배포 검사는 생략하지 않는다.
- 추가 전체 제품 테스트는 후보에서 60개 실패/3,543개 통과, 변경 전 실행본에서 61개 실패/3,539개 통과였다. 변경 전에도 재현되는 테스트 불일치를 이번 인증 기능의 통과 결과와 구분한다. 전체 제품 테스트가 통과했다고 주장하지 않는다.

## 개발 중 확인 방식

이번 작업은 기존 HTTPS 주소에서 확인한다. 단순 LAN HTTP 주소는 `__Host-` 보안 쿠키와 OAuth 복귀 주소 검증을 만족하지 않으므로 이를 위해 보안 쿠키나 허용 origin 정책을 완화하지 않는다. 수정 반영 후 같은 주소를 새로고침한다.

참고: [네이버 앱 설정](https://naver.github.io/naver-openapi-guide/appconf.html), [Supabase Auth 설정](https://github.com/supabase/auth/blob/master/internal/conf/configuration.go).
