## 근거를 구분하는 기준

1. **공식 계량값:** 원자료의 정확 식품·상태·크기·관측단위·관측량·무게를 보존한다. 출처 URL/버전/원본 해시/식품 및 portion ID를 남긴다.
2. **공식 레시피 병기값:** 특정 레시피의 ‘몇 장에 몇 g’이라는 근거다. 일반 식품의 고정 밀도·모든 크기의 평균으로 과장하지 않는다.
3. **승인된 서비스 대표값:** 사용자가 승인한 편의 기준임을 명시한다. 실제 g 입력이 우선하며 공식값과 구분한다.
4. **범위가 불명확한 값:** 숫자가 같아도 형태·가식부·제품·계량도구가 다르면 추가 확인 대상으로 남긴다. 근거가 없다고0이나 ml=g로 채우지 않는다.

기존 출처/승인 row는 원래 검토 이력으로 보존한다. 이번 분류와 제한은 감사 자료에 별도로 기록했으며 과거 출처를 재작성하지 않았다. 새 승인값은 기존 nutrition_sources → measurement_source_evidence → piece_unit_weights에 추가했다.

## 기존 값의 적용 제한

- 고춧가루7.4g/15ml는 공식 표의 고운 형태, 마늘11.3g은 다진 형태, 후추8.6g은 가루 형태에 해당한다. 일반 이름을 같은 형태로 해석하는 현재 대표 정책을 모든 상태의 실측값으로 설명하면 안 된다.
- 공식 안내의 밥숟가락10~13ml·종이컵 약180ml는 계량큰술15ml·계량컵200ml와 다르다. 현재 계산기의 일괄 치환은 이번에 유지했으며 후속 정책/구현 대상이다.
- 달걀50g은 기존 서비스 medium 코드에 저장되어 있지만 USDA 크기 분류로는 large와 같다. 양배추900g·레몬60g도 원자료908g·58g을 그대로 옮긴 공식값이 아니다.
- 컵/스푼 계량은 분말 담기 방식과 제품에 따라 달라질 수 있다. 부피값은 estimated 품질로 계산하며 직접 측정 g와 구분한다.

## 보완 데이터와 검증

[보완 명세](data/ingredient-piece-supplement-20261009.json)의 USDA FDC169251 / portion84529를 공식 CSV에서 직접 확인했다. 생 양송이버섯의 medium1개18g이며 현재 RDA ‘양송이버섯, 생것’100g 영양 연결과 식품·상태가 일치한다. 이를3개에 사용하면54g이다. 새 값 역시 개체 차이가 있는 대표 계량값이다.
