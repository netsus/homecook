# 미사용 테스트 재료 선택 목록 정리

상태: 운영 DB·웹 반영 및 실제 검색 확인 완료.

사용자가 연어오븐구이·고추김치를 삭제한 뒤 화이트크림·해물육수(액체)도 삭제하도록 요청했다. 삭제된 두 레시피의 재료 행과 과거 저장본은 아직 재료 ID를 참조하므로 물리 행을 없애지 않고 **현재 검색·선택 대상에서 제거**했다. 현재 레시피·팬트리·장보기·직접 식사기록 참조는 각각0건이었다. 과거 기록 보존을 위해 삭제된 레시피의 재료 행, 불변 영양/내용 저장본, 동의어와 원자료는 유지한다.

| 재료 | 처리 |
| --- | --- |
| 화이트크림 | 기존 카탈로그 excluded 상태에 웹/SQL 선택 제한을 추가 |
| 해물육수(액체) | 카탈로그 umbrella→excluded, 웹/SQL 선택 제한 추가 |
| 해물육수코인 | 별개 재료이므로 계속 선택 가능 |

기존 선택 제외 ID/이름 배열만25→27로 확장했다. 새 공통 추상화·의존성·데이터 삭제 우회는 추가하지 않았다. 화이트크림과 액체 해물육수의 보존용 물리 행2개는 남으며 전체 ingredients 행 수도1,936개로 유지한다. 이는 재료 물리 삭제가 완료됐다는 뜻이 아니다.
