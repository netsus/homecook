사용자는 상세 재료 화면 연결을 보류하고, 음식/제품은 향후 실제 상품 검색과 역할을 정리하며, 중복 이름20개는 대표 재료 동의어로 통합하는 방향을 선택했다. 이번 우선 범위는 **기본·상세 재료 영양 미연결61개**다. 상세 화면·상품 검색·동의어 통합 구현은 이번 범위에 추가하지 않는다.

## 승인한 대표값 기준

품종·색·크기·재배 방식까지 완전히 일치하는 행만 허용하던 기준을 조정한다. 같은 식품과 가식부·기본 상태의 공식자료를 일반 참고값으로 선정하고 대표 기준을 명시한다. 다른 식품/부위·생것과 건조·첨가물·농축비·제품 배합을 구분하며, 여러 자료를 임의 평균하거나 미측정값을0으로 만들지 않는다.

대표값은 실제 상품의 실측값이나 해당 상품의 등급·원산지를 확정하는 정보가 아니다. 링크의 `decision_reason`에 `user_approved_representative:`와 조건을 기록하고, 공개 카탈로그 definition에도 영양 참고기준을 명시한다. 공유 원자료는 수정하지 않으며 단위·부피·개당 무게를 새로 복제하지 않는다. 기존 `manual_source` 검토 경로를 사용하며 권한/승인/영양 불변성 검사를 변경하지 않는다.
