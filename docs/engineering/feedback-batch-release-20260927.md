## DB·백업

- exact full-local 운영 PostgreSQL과 연결된 볼륨을 확인했다. 운영 이력 185개가 저장소 원본 SHA와 모두 일치하고 신규 12개를 준비했다.
- 기존 암호화 전체 플랫폼 백업·외장 사본·복원 증거가 24시간 안이며 실제 인증 검증을 통과했다. 이를 이유 없이 재실행하지 않았다.
- 변경 직전 DB 전체 custom dump는 116,542,485 bytes, SHA-256 `e3ef9505ea656e30846e070a537cf3a433119d1a182a0f40148ffaa49c90850d`다. 목록 및 전체 decode를 확인했다.
- 같은 PostgreSQL 이미지와 원래 역할 구조를 사용한 network-none 격리 환경에서 운영 schema와 185개 이력만 복원한다. 실제 사용자 행은 복원하지 않으며 신규 SQL의 순차 적용·권한·롤백을 확인한다.
- 새 SQL과 이력은 대상·백업·기존 데이터·R2 권한 보존 가드 아래 한 트랜잭션으로 반영한다. 두부조림 중복 제거는 별도 참조 보호 soft-delete 한 건이다.

### 남은 확인과 검증 한계

실제 iPhone 키보드 체감과 로그인 사용자의 이미지 공개·완료 저장 등은 배포 사이트에서 이어서 확인할 수 있다. 이번 공개 HTTPS 확인은 읽기와 비로그인 거절 확인이며 사용자 계정의 실데이터를 임의로 생성하지 않았다.
