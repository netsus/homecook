## 원인과 최소 문법

- 한 자막의 `재료 A + 완전한 수량 / 재료 B + 완전한 수량`을 독립 절로 결속한다. 앞 재료의 수량을 뒤 재료가 빌리지 않는다.
- 완결된 조리 동작 뒤의 이름·수량 절과, 짧은 접속어 뒤의 이름·수량·완결된 사용 동작을 직접 결속한다. 다른 수량·부분 사용·모호량·광고·부정·조건·미래 문맥을 허용하지 않는다.
- 두 이름 뒤의 `수량 + 단위 + 씩`은 각 재료의 공유 수량이다. `씩` 없는 합계 문장은 인정하지 않는다.
- `하나/둘/셋/넷 + 목적격 조사 + 완결된 사용 동작`은 한국어 개수 표현으로만 `개`를 결속한다. 무게·부피로 바꾸지 않는다. 원문 amountRawText와 인용은 그대로 남긴다.
- `선택 사항인데 ... 넣으면`은 원시 행도 optional=true이고, 같은 자막 또는 8초 이내 바로 앞 자막의 선택 선언이 있을 때만 선택 재료의 명시 수량으로 인정한다. 선택 문맥과 수량을 최종 근거에 함께 남긴다. 필수 사용이나 일반 조건부 문장으로 확장하지 않는다.
- OCR·프레임은 자막과 역할을 합쳐 숫자를 만들지 않는다. 기존 역할 보호는 유지하고 자막 자체의 직접 결속만 새 후보로 추가한다. 설명란·작성자 댓글의 실제 충돌은 기존 conflicting 정책을 따른다.
