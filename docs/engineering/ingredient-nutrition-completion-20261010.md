# 재료 영양 보완·분량 교정

상태: 구현·자료 대조 완료, 운영 적용 검증 중.

## 적용 범위

제외 복구와 승인된 3개 중량을 먼저 적용하고, 대표 영양 9개·부분 영양 2개를 보완한 뒤 현재 레시피를 다시 계산한다. 기존 식사 기록과 원래 영양 프로필은 보존한다. 자동 AI API는 계속 꺼 둔다.

- 고추는 생 풋고추, 훈제오리는 조미 훈제 구입 상태, 콩국물은 소금 0.3%를 포함한 공식 자료를 서비스 대표로 사용한다. 다른 종류·조리 상태까지 같은 값이라는 의미는 아니다.
- 사각어묵·초코칩·조미김·바닐라 페이스트·다크 커버춰·크림소스는 검토한 제품 라벨 전체를 별도 대표 프로필로 보존한다. 실제 사용 제품을 특정했다고 주장하지 않는다. 제품 6개에서 없는 식이섬유는 null이다. 바닐라 페이스트의 기준은 100ml를 유지한다.
- 통밀 식빵과 그릭 요거트는 각각 USDA 통밀 빵, 무가당 전지유 그릭 요거트의 전체 8성분으로 보완한다. 이전 자료는 삭제·수정하지 않고 대표 연결만 교체한다.
- 씻은 신김치가 현재 레시피에 있어 신김치의 일괄 배추김치 연결은 보류한다. 종류/상태별 선택이 없는 상태에서 조건부 대표값을 무조건 계산에 쓰지 않는다.

## 마늘과 멸치

엄마표 간장국수 원영상의 자막은 ‘다진마늘 1’이고 숟가락에 담긴 한 덩어리를 넣는다. 영상에 g 또는 ml 측정값은 없다. 사용자가 1숟가락으로 정정하도록 승인했으므로 저장된 10개를 1숟가락으로 교정한다. 기존 서비스의 숟가락=15ml 가정과 승인된 다진마늘 환산 11.3g을 계산에 사용하며, 화면은 ‘다진마늘 1숟가락’으로 유지한다. 11.3g은 영상 속 실측 무게가 아니다. 다른 재료와 마찬가지로 내부 출처 정밀도를 보존하며 이 작업에서 전체 환산값을 반올림하지 않는다.

원문에 ‘국멸치 5g’인 두 레시피는 생멸치 연결을 삶아 말린 대멸치로 교정한다. 국물에 우러난 비율·건더기 제거는 별도 계산 범위이며 이 교정만으로 해결하지 않는다. 레시피 변경과 새 영양·내용 스냅샷 생성은 같은 트랜잭션에서 처리한다.

## 표시와 근거

영양성분 상세에는 확인된 대표 영양 데이터셋에 한해 ‘일부 재료는 승인된 대표 영양값으로 계산했어요. 실제 제품·종류에 따라 달라질 수 있어요.’를 표시한다. 영양과 중량 출처가 같은 구조를 사용하므로 중량·AI 출처를 이 안내로 잘못 분류하지 않는다. 새로운 대표 데이터셋 승인 시 표시 목록도 검토해야 한다.

실사용 3종을 포함한 부분 영양 210종을 조사했다. RDA 206개는 원본 식품명과 일치했고 누락 768칸은 원자료의 ‘-’ 760칸·‘Tr’ 8칸이었다. 파싱 복구로 채울 칸은 0개다. 실제 쓰이는 식빵·요거트를 우선 보완하며 나머지 자료 부족 항목을 0으로 채우지 않는다.

근거: `data/nutrition-completion-batch-20261010.json`, `data/nutrition-completion-research-20261010.json`, `data/garlic-and-partial-nutrition-review-20261010.json`. 운영 완료 여부와 최종 집계는 별도 적용 결과가 확인된 뒤 기록한다.
