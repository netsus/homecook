# 재료 카탈로그 정리 — 돼지고기·갯기름나물·데친 이름

상태: 2026-09-15 KST 적용 완료, 앱 배포 대기

## 적용 결과

- 구운/삶은/생것으로 세분화된 사용자 지정 돼지고기 18종과 노지/하우스/어린잎으로 세분화된 갯기름나물 8종을 선택 가능한 재료에서 제외했다.
- 26종 모두 RDA nutrition link의 immutable provenance가 있어 hard delete하지 않고 stable ingredient id 기반 비활성 정책으로 숨긴다.
- 사용자 recipe/pantry/shopping/meal-log 참조는 돼지고기 살코기 생것 recipe 2행뿐이었다. 두 행은 기존 `돼지고기`로 재연결했고 active recipe는 양배추감자전 1행이다. 다른 사용자 데이터 참조는 0이었다.
- 일반 `돼지고기`에는 `돼지고기 · 살코기 (생것)` RDA 8개 nutrient value/status를 변경 없이 복제한 대표 profile을 연결했다.
- 기존 `갯기름나물`, `돼지고기`, 돼지고기 갈비/뒷다리/등심/목심/사태/안심/앞다리 재료는 유지한다.
- 1차로 suffix가 정확히 `(데친것)`인 87개 standard name을 `데친 {재료명}`으로 변경했다.
- 사용자 후속 승인으로 괄호 상태 51종과 가운데 점 이름 전체를 자연어로 확장했다. 후보 1,006개 중 960개 이름을 변경했고 내부 중복·기존 이름 충돌·미지원 suffix는 모두 0이었다.
- 생것 외 조리·가공 상태는 앞말로 이동한다: `(삶은것)→삶은`, `(찐것)→찐`, `(구운것(팬))→팬에 구운`, `(말린것)→말린`, `(통조림)→통조림` 등이다. `(생것)`은 기본 상태라 생략한다.
- 색상은 자연스러운 관형어로 이동한다: `파프리카 · 빨간색 (생것)→빨간 파프리카`, `양배추 · 적색 (삶은것)→삶은 붉은 양배추`다.
- 색상이 아닌 가운데 점은 순서를 유지한 공백으로 바꾼다: `당근 · 뿌리 (삶은것)→삶은 당근 뿌리`다.
- 변경 전 standard name은 synonym으로 보존한다. 최종 DB의 trailing 괄호 이름과 가운데 점 이름은 각각 0개다.
- 갯기름나물 재배·성장 수식어는 재료 앞에 둔다. 예: `갯기름나물 노지 어린잎`이 아니라 `노지 어린잎 갯기름나물`, 데친 상태면 `데친 노지 어린잎 갯기름나물`이다.
- 노지/하우스/어린잎 8개 세부 항목은 계속 선택 불가이며 사용 가능한 대표는 `갯기름나물`이다. 조리 상태가 다른 `데친 갯기름나물`은 기존 원칙대로 별도 유지한다.
- 사용자 후속 승인으로 생것을 기본 상태로 정했다. 선택 가능한 이름 251개에서 `생 ` prefix를 제거하고 `(생것)` 신규 입력도 prefix 없이 정규화한다. 예: `생 빨간 파프리카→빨간 파프리카`, `생 노지 어린잎 갯기름나물→노지 어린잎 갯기름나물`이다.
- `돼지고기 갈비/목심/사태/안심`과 충돌하는 비활성 RDA 원본 4행만 내부 provenance 이름에 `생 `을 유지한다. stable id 비활성 정책으로 검색·선택·등록에는 노출되지 않는다.

## 같은 작업의 recipe 정리

- 구운채소와 간장레몬 소스의 올리브 오일 적당량을 20g QUANT로 변경했다.
- 테스트 recipe `집밥 김치찌개`는 soft delete했다.
- 활성 recipe의 TO_TASTE는 0행이 됐다.

## 앱 정책

- ingredient search direct/synonym 결과에서 26개 id를 제외한다.
- YouTube ingredient resolution에서도 direct/synonym 후보로 사용하지 않는다.
- 수동 recipe 생성에서 비활성 id를 not_found로 처리한다.
- 기존 immutable nutrition provenance와 과거 참조 복원 가능성은 유지한다.
- 새 YouTube ingredient 등록 이름에도 같은 자연어 정규화를 적용해 괄호/가운데 점 형식이 다시 유입되지 않게 한다.
