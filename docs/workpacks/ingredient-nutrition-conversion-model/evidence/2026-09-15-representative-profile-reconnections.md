- 파프리카는 빨간·노란·주황·초록 생것의 core 영양 차이가 작아 실제 RDA 원본인 빨간색 생것을 대표로 선택했다. 합성 평균 profile은 만들지 않았다.
- `빨간/빨강/노란/노랑/주황/초록 파프리카`와 어순을 바꾼 색상 표현까지 대표 `파프리카` synonym 10개를 등록했다.
- 색상별 데친것·찐것은 조리 상태가 다르므로 유지한다.

## 운영 안전 확인

- 직접 profile 공유 link는 exact-name 검증에 실패해 전부 rollback한 뒤, target 이름의 source item/profile/value를 원본값 그대로 만든 정식 승인 경로로 적용했다.
- recipe reference와 synonym 변경은 generation-active 내부 writer marker를 한 transaction에서 설정·해제했다.
- commit 뒤 `_internal_generation_writer_txid` 잔여 marker는 0이다.

## 2026-09-15 개당 중량·공공 계량 근거 후속

- 테스트 recipe `토블론`, `ㄴㅇㄹㅇ`는 복구 가능한 soft delete로 처리했다.

양조간장·양조식초는 해당 세부 제품의 밀도 실측이 아니라 공공 실측표의 일반 간장·식초 대표값이다. B 근거는 공식 recipe에 병기된 실사용 환산이며 실험실 밀도 표가 아니다. 2026-09-15 사용자 승인에 따라 표의 값과 물 15g/15mL를 active approved conversion assignment로 등록했다.

공공 실측표의 비액체 재료도 고운 고춧가루 7.4g/15mL, 마늘·다진마늘 11.3g/15mL, 후추 8.6g/15mL로 함께 등록했다. 총 15개 ingredient assignment가 현재 active approved이며, 기존 28개 부피↔무게 blocker 중 `다시다 0.5스푼` 1행만 남는다.

### 2026-09-15 최종 환산 후속

- 다시다 `0.5스푼=5g`, 즉 10g/15mL를 사용자 승인 active assignment로 등록했다.
- 청오이 `medium 1개=200g`을 사용자 승인 active piece 표준으로 등록했다.
- 이에 따라 기존 부피↔무게 blocker 28행과 개당 중량 blocker 15행은 모두 해소됐다.
- 새 환산으로 계산 대상이 늘면서 `NUTRIENT_VALUE_MISSING`은 과거 40건에서 현재 48건으로 증가했다. 분포는 식이섬유 17, 포화지방 15, 당류 11, 나트륨 5이며 탄수화물·단백질·지방 누락은 0이다.
